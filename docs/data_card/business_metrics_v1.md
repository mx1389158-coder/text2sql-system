# 星云智家业务口径目录 v1.1

机器可读来源为 `data/processed/semantic_catalog_v1.json`。Prompt 只检索相关定义并携带
`key@version`，不得在代码中另写一套未版本化口径。

| 指标 | 默认/推荐定义 | 必须澄清的维度 |
| --- | --- | --- |
| 有效订单 | `status in ('paid','completed')`，取消订单不计 | 下单时间或支付时间 |
| 销售额 | 成功支付金额或有效订单应收金额二选一 | 金额来源、状态、时间字段 |
| 退换货率 | approved return/exchange 明细数 ÷ 同期有效订单商品明细数 | 订单/申请时间、是否含仅退款 |
| 重复报修 | 同设备前一张非取消工单后 7 天内再次创建非取消工单 | 判定窗口 |
| 重复报修率 | 7 天内重复报修设备数 ÷ 窗口内报修设备数 | 观察窗口、7/30 天、设备/工单分子、报修/全部设备分母 |
| 处理时长 | `resolved_at-created_at`，仅 resolved 且未取消 | 创建或受理起点、未解决是否计入 |
| 满意度 | `satisfaction_surveys.score` 算术平均并同时报告评价数 | 时间窗口 |
| 升级成功率 | 成功升级次数或设备数 ÷ 全部尝试次数或设备数 | 次数/设备、时间窗口 |
| 活跃设备 | 指定窗口内发生升级或报修等业务事件 | 窗口、活跃事件 |
| 故障率 | 故障设备数或工单数 ÷ 激活或活跃设备数 | 四种分子/分母组合 |
| 库存 | `inventory` 当前快照 quantity 汇总 | 当前/历史时点、是否按仓库拆分 |

所有澄清选择必须进入查询状态机并在恢复后重新执行 Schema Linking、安全校验和只读查询。
空结果是合法结果，不得自动解释为 SQL 错误或切换口径。
